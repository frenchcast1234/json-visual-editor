<div align="center">
    <h1>JSON Visual Editor</h1>
    <i>alias JSON VE</i><br>
    is a visual JSON editor made with flutter.
</div>

## Features

### Files
* Open file
* Open recent file
* Save
* Save as
* New file

### Editor
* Add value/list/map at the end of a map/list
* Add value/list/map before/after an element
* Delete element
* Editing key/value
